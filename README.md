# LinguaFiRST

Bikol ↔ English learning app. This repository contains **two deployable projects**:

| Folder    | Role                          |
| --------- | ----------------------------- |
| **`client/`** | Vite + React (deploy separately) |
| **`server/`** | Express API + MongoDB + Cloudinary uploads (deploy separately) |

- Local setup: see **`client/README.md`** and **`server/README.md`**.
